# Thomas Lacombe — Portfolio

Personal portfolio website for Thomas Lacombe, Machine Learning Engineer.

**Live site:** [thomas-lcb.github.io/Resume](https://thomas-lcb.github.io/Resume)

---

## What it is

A single-page portfolio presenting my profile, skills, experience, education, and projects. It is fully static — no framework, no build step, just three files (`index.html`, `style.css`, `script.js`) served directly via GitHub Pages.

The site is bilingual (EN/FR), with a language toggle that persists across sessions.

## Tech

- Vanilla HTML / CSS / JavaScript
- [Three.js r134](https://threejs.org/) for the 3D neural network animation in the hero
- Google Fonts (Poppins) + Font Awesome 6 — both via CDN
- GitHub Pages for hosting

## Sections

- **Hero** — 3D neural network canvas + animated particle background
- **About** — short bio and contact info
- **Skills** — bento grid with skill categories and proficiency gauges
- **Experience / Education** — interactive expandable timeline
- **Projects** — horizontal carousel with per-card canvas animations (7 types)
- **Contact** — links and downloadable CV

## Versions

**v1** — built entirely by hand. Simpler layout, more classic CSS animations, no canvas-heavy visuals.

**v2** (current) — complete redesign with Three.js neural network, custom particle systems, liquid glass card style, interactive carousel, and various performance optimisations. Built with the help of Claude Code.
